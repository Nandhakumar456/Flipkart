## 📝 About This Project
This project involves designing a high-fidelity prototype of the Flipkart mobile/web application using Figma. The goal was to study the existing design patterns of one of India's largest e-commerce platforms and replicate or enhance the user flow for better accessibility and visual appeal.

## Key Design Features:
- **Home Screen:** Structured product categories, promotional banners, and personalized recommendations.
- **Product Search & Filters:** Streamlined interface for finding products with advanced filtering options.
- **Product Detail Page (PDP):** Clear call-to-action buttons (Buy Now/Add to Cart), image carousels, and review sections.
- **Checkout Flow:** A simplified, multi-step process designed to reduce cart abandonment.
- **Responsiveness:** Designs optimized for both Mobile and Desktop views.
